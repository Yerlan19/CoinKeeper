# CoinKeeper - Personal Finance Management App

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
cd keep-coins
npm install
```

### 2. Запуск Backend

В отдельном терминале:

```bash
cd back
npm install
npm start
```

Backend запустится на `http://localhost:3000`

### 3. Запуск Frontend

```bash
cd keep-coins
npm run dev
```

Frontend запустится на `http://localhost:5173`

## 📦 Сборка для production

```bash
npm run build
npm run preview
```

## 🔧 Конфигурация

### Переменные окружения

Создайте файл `.env` в папке `keep-coins`:


Для production замените на URL вашего backend.

## 🐛 Решение проблем

### Белый экран при запуске
1. Проверьте, что backend запущен на порту 3000
2. Проверьте консоль браузера (F12) на наличие ошибок
3. Очистите кеш Vite: `rm -rf node_modules/.vite`

### Ошибка 401 при логине
1. Убедитесь, что backend запущен
2. Проверьте, что endpoint `/users/login` доступен
3. Проверьте правильность email и password

### Ошибки с AG Grid
- AG Grid полностью заменен на MUI DataGrid
- Если видите ошибки с AG Grid, проверьте, что все импорты обновлены

## 📝 Тест-кейсы для преподавателя

### Тест-кейс 1: Регистрация и логин
1. Откройте приложение
2. Нажмите "Register"
3. Заполните форму (name, email, password)
4. После регистрации вы должны быть автоматически залогинены
5. Перезапустите backend
6. Выйдите и войдите снова - должно работать

### Тест-кейс 2: CRUD операции
1. Войдите в систему
2. Перейдите на `/transactions`
3. Создайте новую транзакцию
4. Отредактируйте созданную транзакцию
5. Удалите транзакцию
6. Экспортируйте данные в CSV

### Тест-кейс 3: Защита маршрутов
1. Выйдите из системы
2. Попробуйте открыть `/dashboard` напрямую
3. Должно перенаправить на `/login`
4. Войдите в систему
5. Теперь `/dashboard` должен открыться

## 🚀 Деплой

### Frontend на Netlify
1. Подключите GitHub репозиторий к Netlify
2. Настройте переменную `VITE_API_URL`
3. Netlify автоматически задеплоит приложение

### Backend на AWS
1. Создайте базу данных на AWS RDS
2. Соберите JAR файл (для Spring Boot) или используйте Docker
3. Следуйте инструкциям в `back/DEPLOYMENT_README.md`
